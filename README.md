# 按表格批量改文件名

> 篝火出品 · 收录于篝火 App 应用区

按 Excel 映射表批量重命名

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/batch-rename/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `batch-rename_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `batch-rename_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `batch-rename_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

**按映射表改名**
1. 点「选择文件夹」（或把文件夹拖进窗口），只处理这一层的文件，不进子文件夹，隐藏文件跳过。
2. 「新名字从哪来」选「按映射表」，点「导入映射表」（或把表格拖进窗口），支持 .xlsx 和 .csv（自动识别 UTF-8 / GBK）。表头写「原文件名」「新文件名」；没有表头时取第 1 列、第 2 列。
3. 没有映射表时，点「导出文件清单」得到带原文件名的表格，在「新文件名」列填好再导入。
4. 在「改名预览」里核对前后对照。每行有检查结果：可改名、名字没变、找不到原文件、新名字不合法（含 `\ / : * ? " < > |`、Windows 保留名、以空格或句点结尾、超过 255 字节）、会覆盖已有文件、新名字重复、原文件重复出现。有问题的行不会改，其余行照常改。
5. 点「执行改名」。文件夹里会留一份 `改名撤销记录-时间.json`；点「撤销上次改名」或「打开撤销记录」可还原。

**按序号规则改名**：选「按序号规则」，填名字模板（`{序号}` 换成编号，`{原名}` 换成不含扩展名的原文件名）、起始序号、位数，可只改指定扩展名。按文件名自然顺序编号（图2 排在 图10 前），扩展名保持不变。

**其他说明**
- 新名字没写扩展名时默认沿用原扩展名（可取消勾选）；原文件名不写扩展名也能对上（同名文件只有一个时）。
- 永远不覆盖已有文件；文件名比较不分大小写。
- 全部在本机完成，不联网。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 选择 `samples/巡检照片` 文件夹，导入 `samples/改名对照表.xlsx`（或 .csv），不改选项 | 预览 6 行：3 行「可改名」（`IMG_2041.png`→`光谷店-门头.png`，`IMG_2042.png`→`光谷店-货架A区.png`，`IMG_2043.png`→`汉街店-门头.png`），`IMG_2044.png` 为「会覆盖已有文件」，`IMG_2045.png` 为「新名字不合法」（含 `/`），`IMG_2049` 为「找不到原文件」 |
| 点「执行改名（3 个）」（请先复制一份文件夹再试） | 文件夹里 3 个文件变成新名字，其余文件不变，并生成 `改名撤销记录-*.json` |
| 点「撤销上次改名」 | 文件名全部恢复，与改名前一致 |
| 选「按序号规则」，模板 `照片-{序号}`，起始 1、位数 3，只改 `png` | 7 个 png 按自然顺序改为 `照片-001.png` … `照片-007.png`（与现有文件重名的行会标出，不覆盖） |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
